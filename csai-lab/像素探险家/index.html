物理本质

计算机里没有 0 和 1！

其实计算机的芯片里只有一根根微小的电线。当通电（高电平）时，我们记作 1；当断电（低电平）时，我们记作 0。

一个开关就是 1位 (Bit)。如果把 8 个开关放在一起，就是 1字节 (Byte)！

十进制 (人类认识的数) 0
十六进制 (程序员简称) 0x00

数据对齐

像素是如何排队的？

其实在计算机的内存中，一幅图像就是一长排没有任何“回车键”的颜色数字。

计算机在解开这张图时，必须读取文件头部的宽度信息（宽度分辨率），每读满宽度数，就命令显示器“另起一行”！

拉动右侧的换行宽度滑块，看一看错误的宽度是如何让图形发生崩塌和变形的吧！
